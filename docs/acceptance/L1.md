# Acceptation L1 : preuves

Reference: `docs/design-v2.md` section 10.3, L1. Les points 3, 4 et 5 sont prouves ci-dessous (sorties reelles, lancees en local).
Les points 1, 2, 6 et 7 dependent d'actions du proprietaire dans son compte AWS: ils sont marques « a faire apres bootstrap ».

## Point 1. Un push sur `main` deploie `dev`, aucun secret `AWS_*` dans le depot

**A faire apres bootstrap par le propriétaire** (`docs/ops/bootstrap.md`, puis `vars.DEPLOY_ENABLED=true`). Preuve a coller: lien du run `deploy` et sortie de `gh secret list` (seul `AWS_ACCOUNT_ID` attendu, aucune cle d'acces).

## Point 2. Test negatif OIDC

**A faire apres bootstrap par le propriétaire**: un second depot prive de test tente d'assumer le role; coller la sortie de l'echec `AssumeRoleWithWebIdentity`.

## Point 3. Le test des tags echoue quand on retire un tag, et passe sinon
